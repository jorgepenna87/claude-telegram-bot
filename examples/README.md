# Exemplos de personalidade

3 exemplos prontos pra você se inspirar / colar e adaptar no seu `CLAUDE.md`:

| Exemplo | Pra quem |
|---|---|
| [Secretária de escritório](personalidade-secretaria.md) | Profissional liberal que precisa de assistente técnico de trabalho |
| [Tutor de estudos](personalidade-tutor.md) | Estudante (próprio ou filho/a) — método socrático, não dá resposta de mão beijada |
| [Coach de produtividade pessoal](personalidade-coach.md) | Rotina cheia, brain dump matinal, revisão semanal |

## Como usar

1. Escolha o que mais se aproxima do seu caso
2. Copie o conteúdo do `.md` correspondente
3. Cole no seu `CLAUDE.md` (raiz do projeto)
4. Ajuste os campos `[colchetes]` com seus dados (nome, profissão, etc.)
5. Adicione regras específicas suas conforme for usando

## Refinar com o tempo

A primeira versão nunca é boa. Conforme você usar o bot, anote no CLAUDE.md:
- Coisas que ele fez e te irritaram → adiciona em "Anti-patterns"
- Decisões que ele acertou sem você pedir → adiciona em "Faz sem pedir"
- Coisas que ele deveria perguntar antes → adiciona em "Pede OK antes"
